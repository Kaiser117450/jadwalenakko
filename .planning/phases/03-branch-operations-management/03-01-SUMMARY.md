## Decisions Made

- Publish reducer names explicitly from the runtime entrypoint rather than depending on auto-derived snake_case names, because the generated browser accessors need stable Phase 3 names.
- Keep the admin UI brownfield-compatible in one Astro route and move transport logic into `src/lib/spacetimedb/admin-branch-client.ts`, matching the public client pattern established in Phase 2.
- Treat activation as an `updateBranch` patch generated by `toActivationPatch`, which keeps the runtime surface aligned with the existing reducer set.
